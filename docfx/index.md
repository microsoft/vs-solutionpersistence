# Overview

Shared serializers and models for Visual Studio `.sln` and `.slnx` solution files.

Install it from NuGet:

[![NuGet package](https://img.shields.io/nuget/v/Microsoft.VisualStudio.SolutionPersistence.svg)](https://nuget.org/packages/Microsoft.VisualStudio.SolutionPersistence)

```console
dotnet add package Microsoft.VisualStudio.SolutionPersistence
```

## Highlights

- Read and write traditional text-based `.sln` and XML-based `.slnx` files.
- Manipulate projects and solution folders through a shared object model.
- Preserve user-added XML content and formatting where possible when updating `.slnx` files.

See [Features](docs/features.md) for the full list.
